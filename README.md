A modern, responsive **Single Page Application (SPA)** designed for high-speed burger shop management. This frontend focuses on a seamless user experience, featuring a utility-first design and reactive data handling.

---

### 🌟 Key Features

* **📦 Modular Components:** Clean, reusable Angular components for easy maintenance.
* **🎨 Modern UI/UX:** Styled with **Tailwind CSS** for a sleek, professional, and mobile-friendly look.
* **🔄 Reactive State:** Utilizes **RxJS** for real-time updates of carts and order status.
* **⚡ Live Validation:** Real-time form validation for adding products and processing payments.
* **📱 Fully Responsive:** Optimized for desktop monitors, tablets, and handheld POS devices.
